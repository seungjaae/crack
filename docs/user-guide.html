교량 균열 추출 엔진

1프로그램 개요

1.1해결하는 문제

기존에는 현장에서 균열 폭을 자로 재고, 종이 도면에 손으로 스케치한 뒤, 사무실로 돌아와 CAD에 일일이 다시 옮겨 그렸습니다. 수일이 걸리고 옮겨 적는 과정에서 누락과 오기가 생깁니다.

이 프로그램은 그 과정을 드론 촬영 → 자동 추출로 바꿉니다. 현장 작업자는 폭을 재서 정해진 색 락카로 균열을 덧칠하기만 하면 되고, 나머지는 프로그램이 처리합니다.

1.2핵심 아이디어

균열을 직접 인식하는 것은 어려운 문제입니다. 하지만 콘크리트는 무채색이고 락카는 고채도이기 때문에, 색상 공간에서는 둘이 매우 뚜렷하게 갈립니다. 균열 탐지 문제를 색상 분리 문제로 치환해 난이도를 크게 낮춘 것이 이 설계의 핵심입니다.

그래서 이 엔진은 딥러닝을 쓰지 않습니다. 학습 데이터가 필요 없고, 결과를 설명할 수 있으며, 임계값이 사람이 읽고 조정할 수 있는 값으로 남습니다. 토목 검수 과정에서는 이 점이 중요합니다.

1.3처리 흐름

2설치

2.1요구 사항

  • Python 3.11 이상 (개발·검증 환경은 3.12)
  • Windows / macOS / Linux — 현재 검증은 Windows 11 기준
  • 주요 의존성 — numpy, opencv, scikit-image, rasterio(GeoTIFF), ezdxf(DXF), scipy
  • GUI 를 쓸 경우 PySide6 추가

2.2설치 절차

# 1. 저장소 받기
git clone https://github.com/seungjaae/crack.git
cd crack

# 2. 가상환경 생성
py -3 -m venv .venv

# 3. 설치 (GUI 포함)
.venv\Scripts\python -m pip install -e ".[gui]"

설치가 끝나면 crack(CLI)과 crack-gui(GUI) 두 명령이 등록됩니다.

2.3설치 확인

# 검증용 합성 영상을 만들고 돌려본다
.venv\Scripts\python tools/make_synthetic.py

# 정답과 대조 · 테스트

실제 드론 데이터 없이도 동작을 확인할 수 있도록, 정답 좌표를 아는 합성 정사영상 생성기를 함께 넣어 두었습니다. 자세한 내용은 11장에 있습니다.

현장 조도와 락카 상태에 따라 색상 임계값은 반드시 조정이 필요합니다. GUI 는 그 조정을 위한 도구입니다. 축소본 위에서 슬라이더를 움직이면 검출 결과가 즉시 바뀌는 것을 보면서 값을 맞출 수 있습니다.

3.1실행

# 그냥 실행
crack-gui

# 영상을 바로 열면서 실행
crack-gui ortho.tif

3.3작업 순서

  1. 정사영상 열기

    툴바의 열기로 GeoTIFF 를 선택합니다. 상태바에 영상 크기, GSD(mm/픽셀), 좌표계가 표시되어 파일이 제대로 읽혔는지 바로 확인됩니다.

  2. 보기를 '색상 마스크'로 전환

    현재 임계값으로 어떤 픽셀이 잡히고 있는지가 색으로 표시됩니다. 이 화면이 튜닝의 기준입니다.

  3. 색상별 임계값 조정

    우측 탭(W1·red / W2·yellow / W3·cyan)에서 네 가지 값을 조정합니다. 슬라이더를 놓으면 즉시 반영됩니다.

    슬라이더역할올리면
    색상 시작 / 끝 (H)인식할 색조 범위다른 색조가 포함/제외됨
    최소 채도 (S)가장 중요한 값. 회색 콘크리트를 걸러냄깨끗해지지만 바랜 락카를 놓칠 수 있음
    최소 명도 (V)어두운 픽셀 제외 기준그늘 속 락카를 놓칠 수 있음

    빨강은 색상환에서 H=0 을 감싸고 돌기 때문에 구간이 둘로 나뉩니다. 시작 > 끝으로 두면 자동으로 감싸는 구간이 됩니다.

  4. 노이즈 필터 조정

    최소 길이(이보다 짧으면 버림)와 최소 세장비(길이÷폭, 뭉툭한 것은 버림)를 맞춥니다. 낙엽·흙 얼룩은 세장비에서 걸러집니다.

  5. 추출 실행

    확정된 값으로 원본 해상도 처리를 돌립니다. 별도 스레드에서 동작해 화면이 멈추지 않습니다. 끝나면 자동으로 '추출 결과' 보기로 전환되고 우측에 등급별 개수와 총연장이 표시됩니다.

  6. 내보내기

    DXF / TSV 내보내기로 폴더를 지정해 저장합니다.

  7. 임계값 저장

    현재 임계값을 설정 파일에 저장을 누르면 config/default.toml 에 반영됩니다. 다음부터는 CLI 로 같은 값이 자동 적용되므로, 한 번 튜닝하면 이후 배치 처리에 그대로 쓸 수 있습니다.

4검수와 수정

추출 결과를 그대로 믿고 내보내는 것이 아니라, 확인하고 고칠 수 있게 해 두었습니다. 현장 마커는 사람이 붓으로 칠한 것이라 농도와 굵기가 고르지 않습니다. 흐리거나 끊긴 구간은 자동 추출이 놓치고, 반대로 비슷한 색의 얼룩을 잘못 잡기도 합니다.

4.1색상별로 나눠 보기

세 색을 한 장에 겹쳐 보면 서로 가려 검수가 어렵습니다. 우측 표시할 색상 체크박스로 등급별로 켜고 끕니다. 다른 색은 원본 그대로 남아 있어 위치 대조가 됩니다.

함께 동작하는 것

화면에서 꺼 둔 색상은 클릭 선택에서도 제외됩니다. 보이지 않는 선을 실수로 지우는 일이 없도록 한 것입니다.

4.2잘못 추출된 선 삭제

  1. 선 클릭

    흰색으로 굵게 강조되고, 우측에 선택: #11 W1·red 길이 2,448.9 mm 처럼 정보가 표시됩니다. 클릭 지점에서 가장 가까운 선이 선택됩니다.

  2. 삭제

    선택 삭제 버튼 또는 Delete 키. 지운 선은 어디를 지웠는지 알 수 있도록 회색으로 흐리게 남습니다.

  3. 되돌리기

    Ctrl+Z 로 한 단계씩, 전체 복원 으로 한 번에 되돌립니다.

삭제한 선은 통계와 DXF/TSV 내보내기에서 함께 빠집니다.

4.3놓친 선 직접 그려 넣기

자동 추출이 놓친 균열은 사람이 보완합니다. 색상을 고르고 캔버스를 클릭해 폴리라인을 그립니다.

조작동작
그리기 시작그리기 모드 진입. 색상을 먼저 고릅니다
클릭점 찍기
더블클릭 / Enter선 완료
Backspace마지막 점만 취소
Esc그리던 선 전체 취소

선 하나를 마쳐도 그리기 모드는 유지되어 연달아 그릴 수 있습니다. 직접 그린 선도 자동 추출된 선과 똑같이 선택 · 삭제 · 집계 · 내보내기됩니다.

자동인지 수동인지 구분

TSV 의 source 열이 auto(프로그램 추출) 와 manual(직접 그림) 을 기록합니다. 선을 선택하면 · 직접 그림 이 붙고, 분석 리포트 아래에도 직접 그린 선의 개수가 표시됩니다. 검수 때 어느 선이 사람 손을 탔는지 알 수 있어야 하기 때문입니다.

7기능 상세

7.1정밀 색상 분리

RGB 가 아닌 HSV 색공간에서 분리합니다. RGB 로는 조도가 바뀌면 값이 통째로 흔들리지만, HSV 는 색조(H)·채도(S)·명도(V)가 분리되어 있어 그늘에 들어간 락카도 같은 색조로 인식됩니다.

콘크리트는 채도가 거의 0 이므로, 채도 하한선 하나만으로도 배경의 대부분이 탈락합니다. 빨강처럼 색상환의 0 을 감싸는 색은 구간을 둘로 나누어 처리합니다.

7.2노이즈 제거 — 3단계

그림자, 타이어 자국, 흙 얼룩, 낙엽을 선과 구분해 걸러냅니다.

단계방법걸러내는 것
1 · 색상채도·명도 하한선무채색 콘크리트, 그림자, 타이어 자국
2 · 형태모폴로지 열림/닫힘 + 최소 면적점 노이즈. 끊긴 선은 반대로 이어 붙임
3 · 기하최소 길이 + 세장비(길이÷폭)낙엽, 흙 얼룩처럼 뭉툭한 것
현장 튜닝 시 참고

검증 과정에서 확인된 사실입니다 — 면적 필터는 낙엽을 거의 걸러내지 못합니다. 낙엽은 면적만 보면 충분히 큽니다. 실제로 오검출을 막는 것은 3단계 세장비 필터입니다. 오검출이 나오면 이 값을 먼저 조정하십시오.

7.3벡터화 및 분기 분할

균열은 나뭇가지처럼 갈라집니다. 갈래를 하나의 선으로 뭉뚱그리면 길이가 왜곡되므로, 분기점에서 끊어 각 가지를 독립 세그먼트로 만듭니다.

길이(L)의 정의

  • 시작점–끝점 직선거리가 아니라 균열을 따라간 실연장입니다.
  • 세선화 결과의 계단 현상은 폴리라인 단순화(RDP)로 정리한 뒤 측정합니다.
  • 분기점에 붙는 짧은 잔가지(spur)는 세선화 부산물이므로 자동으로 제거합니다.

7.4실좌표 변환

GeoTIFF 에 들어 있는 측량 좌표계를 그대로 사용합니다(예: EPSG:5186 중부원점). 정사영상 합성 단계에서 이미 정위치가 끝나 있으므로, 별도의 좌표 맞추기 작업이 필요 없습니다. 추출된 선의 좌표가 곧 실제 교량 위의 물리적 위치입니다.

좌표계 단위(미터·밀리미터·피트)를 읽어 mm 로 환산하므로 길이 값은 항상 mm 로 나옵니다. 좌표계가 없는 일반 TIFF 는 설정의 fallback_gsd_mm 을 써서 픽셀 좌표로 처리합니다.

7.5대용량 영상 타일 처리

GSD 0.5 mm 에서는 8 m × 2 m 바닥판 하나가 이미 6,400만 화소입니다. 경간 전체라면 수억 화소가 됩니다. 원본 RGB 를 통째로 메모리에 올리면 감당이 안 되므로, 영상을 타일로 나누어 읽고 화소당 1바이트짜리 등급 라벨맵으로 축약해 누적합니다 (RGB 대비 1/3 메모리).

타일 경계에서 모폴로지 연산이 깨지지 않도록 겹침 여백을 두고 읽은 뒤 중심 영역만 채택합니다. 면적 필터는 타일이 아니라 영상 전체를 조립한 뒤 한 번에 적용하므로, 타일에 걸친 큰 덩어리가 잘못 잘려 나가지 않습니다.

9출력물 규격

9.1DXF — CAD 도면

  • AutoCAD 2010(AC1024) 이상 호환
  • 균열 하나가 LWPOLYLINE 하나. 좌표는 실측 좌표계
  • 등급별로 레이어 분리 — 특정 등급만 켜고 끌 수 있음
  • 길이 텍스트(W1 L=1130mm)를 균열 중앙에 선 방향으로 회전해 배치
  • 텍스트는 별도 레이어(..._TEXT)라 도면에서 한 번에 끌 수 있음
  • 도면 단위는 좌표계에 맞춰 자동 설정(미터 좌표계면 미터)

9.2TSV — 좌표·수량 표

탭 구분 텍스트라 엑셀에서 바로 열립니다. 열 구성은 다음과 같습니다.

열내용
id세그먼트 일련번호
grade등급 (W1 / W2 / W3)
grade_label등급 설명 (예: 0.1mm이상 0.2mm이하)
color인식된 락카 색
length_mm균열을 따라간 실연장 (mm)
paint_width_mm칠 자국의 폭. 검수용 참고값
start_x / start_y시작점 실좌표
end_x / end_y끝점 실좌표
vertices폴리라인 정점 수
sourceauto 자동 추출 / manual 직접 그림
wkt전체 형상 (LINESTRING). GIS 에서 바로 사용
주의

paint_width_mm 은 락카 자국의 폭(약 10 mm)이지 균열 자체의 폭이 아닙니다. 균열 폭 정보는 grade 열이 담고 있습니다.

9.3미리보기 PNG — 검수용

원본을 어둡게 깔고 추출된 선을 겹쳐 그린 이미지입니다. CAD 를 열지 않고도 빠뜨린 균열이나 잘못 잡힌 선이 없는지 한눈에 확인할 수 있습니다.

12.2아직 확정되지 않은 것

중요

설정 파일의 색상 임계값은 합성 데이터 기준의 '출발점' 값입니다. 실제 현장 조도, 락카 변색, 젖은 노면에서는 반드시 재조정이 필요합니다. 이 값을 검증 완료된 설정으로 오해하면 검출률이 떨어집니다. GUI 를 먼저 만든 이유가 이것입니다.

  • 실제 드론 정사영상 — 1~2장이면 임계값 튜닝을 시작할 수 있습니다.
  • 바닥판 실제 치수 — 영상의 픽셀 크기를 알아야 타일 크기를 맞출 수 있습니다.
  • PoC 납기 — 우선순위 조정에 필요합니다.
